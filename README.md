# Furqan Rehmat — Master CV

Master CV source in Markdown format. Generated to DOCX and PDF using a custom Python automation script.

## Repository Structure

- `Furqan_Rehmat_Master_CV.md` — Source CV in Markdown
- `tailored/` — Tailored CVs for specific roles
- `output/` — Generated DOCX/PDF files (excluded from Git)
- `README.md` — This file
- `.gitignore` — Git ignore rules

## How to Generate

1. Clone the repository
2. Run the Python script from `cv-tools`
3. Generated files are saved in the `output/` folder
